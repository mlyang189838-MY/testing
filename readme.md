# MP3 語音轉 Word 文字檔

這是一個使用 Streamlit 與 Faster-Whisper 的 MP3 語音轉文字網頁應用。

## 功能

- 上傳 MP3 檔案
- 選擇 Whisper 模型
- 支援中文、粵語、英文或自動語言偵測
- 將語音轉為文字
- 產生 Word（.docx）檔案
- 線上下載 Word 檔案

## 部署

1. 將本專案上傳至 GitHub。
2. 前往 Streamlit Community Cloud。
3. 使用 GitHub 帳號登入。
4. 選擇本 repository。
5. 主程式檔案選擇 `app.py`。
6. 點選 Deploy。
